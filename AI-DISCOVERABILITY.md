# ProofGraph — AI Discoverability & Knowledge Completeness

## 1. What is AI Discoverability?

AI Discoverability is a grounded diagnostic methodology to measure whether an entity has established sufficient unambiguous, verified, and structured evidence for autonomous AI agents to accurately synthesize facts about it.

It is **NOT** an SEO ranking algorithm or manipulative score. It is an objective factual diagnostic.

---

## 2. The 8-Point Knowledge Completeness Framework

| Diagnostic Check | Requirement | Goal for AI Agents |
| :--- | :--- | :--- |
| **1. Identity Clarity** | Canonical name, description, and slug | Resolves "Who is this?" unambiguously |
| **2. Source Coverage** | Multiple authoritative domain records | Eliminates single-point-of-failure hallucinations |
| **3. Entity Consistency** | Valid canonical URL & documented aliases | Unifies variations (e.g. `AI Build Infra` vs `aibuildinfra`) |
| **4. Relationship Coverage**| Explicit graph edges (`DEVELOPS`, `OWNS`) | Discovers connections across projects and services |
| **5. Evidence Availability** | Granular text excerpts with SHA-256 hashes| Guarantees traceable citations |
| **6. Freshness** | Recent verification timestamps | Prevents outdated obsolete assumptions |
| **7. Technical Footprint** | Repositories, packages, or registries | Confirms software legitimacy (GitHub, npm, PyPI) |
| **8. Third-Party Corroboration** | Independent registries / publications | Validates real-world external presence |
